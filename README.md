# pratix-net-worth-calculator-base-aligned-v1-stable

This repository contains a **client-side Pratix.io calculator**. It is ready for GitHub and Vercel deployment, retains its calculation functionality, supports **12 interface languages**, and includes a persisted light/dark theme.

## Deployment

Push this folder to a GitHub repository. In Vercel, import the repository and deploy it as a static site with no build command. The root URL redirects to the calculator page, and the calculator remains available under `/tools/net-worth-calculator.html`.

## Local verification

Run `node scripts/verify.mjs` from the repository root. No runtime API keys, server, user account, or build step are required.
